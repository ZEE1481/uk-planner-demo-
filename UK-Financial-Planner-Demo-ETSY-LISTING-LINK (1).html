Help & User Guide

Quick start

1. Setup
Enter your name, year, tax assumptions and income.
2. Accounts
Add your current, savings, cash and investment balances.
3. Budget
Set planned income and spending by month.
4. Transactions
Record actual income and expenses or import a CSV.
5. Plan
Use goals, emergency fund, debt and forecasts.
6. Review
Use health score, analytics and annual reports to improve decisions.

Offline & privacy

This application is designed to run locally. Your data is stored in this browser on this device. It does not require an account or financial login.

Backup best practice

Export a JSON backup regularly and keep a copy somewhere safe. Restoring a backup replaces the current application data.

Important

Tax, pension, student-loan and investment calculations are planning estimates. Always verify regulated or tax-sensitive figures with official UK sources or a qualified adviser.

Data safety

Use Settings → Export Backup before major changes.

CSV safety

Never import a file containing passwords, PINs or banking login credentials.

Recommended routine

Update transactions weekly, review bills monthly and run a financial review each quarter.
